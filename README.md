# cbstartups.com.br

Site estático da Companhia Brasileira de Startups.

- `/` português, `/en/` inglês, `/es/` espanhol
- GitHub Pages: Settings → Pages → Deploy from branch → main / (root)
- DNS: apontar cbstartups.com.br para o GitHub Pages (registros A 185.199.108.153, .109, .110, .111) e marcar "Enforce HTTPS"
